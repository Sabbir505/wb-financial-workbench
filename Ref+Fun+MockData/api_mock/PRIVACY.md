# 模拟数据合规与脱敏说明（PRIVACY）

## 数据来源与合规基线

本目录全部样例数据来自**法定公开披露渠道**：

- 巨潮资讯网（cninfo）上市公司公告原文（定期报告/质押/回购/激励等）
- 深交所互动易公开问答
- 新浪/腾讯公开行情接口（收盘价、换手率、资金流向）

其中出现的公司名称、控股股东/实控人姓名（如金闯、吕新民等）、持股数量、
财务数字，均为上市公司依法必须公开披露的信息，**不属于敏感个人信息**。

## 明确不含的内容（每次打包前由 `check_privacy.py` 强制验证）

- 任何 API 密钥 / 令牌 / 密码（本系统密钥仅存于仓库根 `.env.local`，gitignore，从不进入样例）
- 临时隧道地址（*.trycloudflare.com）
- 手机号、身份证号、邮箱等个人信息
- 内网拓扑信息（IP/端口映射仅出现 127.0.0.1 回环地址，属开发约定）

## 使用方法

```bash
python check_privacy.py [目录]   # 默认扫描本目录；零命中 exit 0，发现疑似 exit 1
```

打包（zip/上传仓库/提交论文附件）前**必须**运行一次；WB 仓库 vendor 目录同理。
最近一次验证：2026-11-06，60 个条目零命中。

## 样例真实性说明

样例取自 KG-Palantir 真实运行（斯迪克 2026Q3 主线及锚点池公司），
时间戳为系统真实生成时间；不含任何虚构人物或联系方式。
审核人字段（如 "张研"）为占位示例名，非真实自然人。
